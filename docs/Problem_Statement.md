# Problem Statement

## 1. Title
Hospital Dashboard

## 2. Domain
Healthcare / Hospital Management

## 3. Who is the user?
- Admin – Manage hospital operations and view reports
- Doctor – View patients and manage appointments
- Receptionist – Register patients and book appointments

## 4. What problem are we solving?
Hospitals may face difficulties in managing patient records, appointments, doctors, beds, medicines and billing separately. Manual work can cause delays and data errors. It is difficult for administrators to get the overall hospital status quickly.

## 5. Proposed Solution
The Hospital Dashboard is a centralized web application that manages patients, doctors, appointments, beds, medicines and billing. It provides a dashboard with important hospital information and reports for better decision-making.

## 6. Core Entities / Database Tables
- Users
- Patients
- Doctors
- Appointments
- Beds
- Medicines
- Billing

## 7. User Roles & Permissions
- Admin – Full access to manage hospital data and reports
- Doctor – View patient details and appointments
- Receptionist – Register patients and manage appointments

## 8. Success Criteria
A user should be able to register a patient and book an appointment within a few minutes, while the admin should be able to view hospital statistics such as patients, appointments, available doctors, beds, medicines and billing.

## 9. Out of Scope
- Online video consultation
- Online pharmacy delivery
- Real-time ambulance tracking
- Advanced AI diagnosis

## 10. Chosen Track
Java (Spring Boot)
